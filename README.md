# LEGOSwarm
LEGOSwarm is a research platform to develop [WEAVE](WEAVE.md), a system that enables autonomous robotic construction. [WEAVE](WEAVE.md) employs a [Foreman](Foreman.md) and [Workers](Worker.md) to assemble complete LEGO kits purely from visual input of the LEGO instruction booklet. Developed by [Loom Robotics](https://loom-robotics.com/).

## Code
Explore and download the code at [LEGOSwarm-repo](https://github.com/LoomRobotics/legoswarm-repo) The repo is private until we complete software development.
